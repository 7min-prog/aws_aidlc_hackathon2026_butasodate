# Unit of Work Dependency

## 依存関係マトリクス

| ユニット | 依存先 | 依存内容 |
|---------|--------|---------|
| ユニット1（認証） | なし | 最初に実装 |
| ユニット2（記録+ヘルス） | ユニット1 | 認証トークン、ユーザーID |
| ユニット3（アバター） | ユニット2 | ポイント加算/減算の入力元 |
| ユニット4（バトル+ソーシャル） | ユニット3 | アバターステータス・スキル参照 |
| ユニット5（管理画面） | ユニット1 | 認証（admin group）。データはユニット2以降で蓄積 |

## 実装順序と並行開発

```text
時間軸 →

[全員] ユニット1 → ユニット2 → ユニット3 → ユニット4
                    ↓
[1人]              ユニット5（並行着手）──────────→
```

## 依存関係図

```text
ユニット1（認証）
    │
    ├──→ ユニット2（記録+ヘルス）
    │        │
    │        └──→ ユニット3（アバター）
    │                 │
    │                 └──→ ユニット4（バトル+ソーシャル）
    │
    └──→ ユニット5（管理画面）※並行
```

## インターフェース契約

| 提供元 | 提供先 | インターフェース |
|--------|--------|----------------|
| ユニット1 | 全ユニット | JWT トークン、userId |
| ユニット2 | ユニット3 | RecordingService → AvatarService.addPoints() |
| ユニット2 | ユニット3 | HealthSyncService → AvatarService.deductPoints() |
| ユニット3 | ユニット4 | AvatarService.getAvatar()（ステータス・スキル参照） |
| ユニット1〜4 | ユニット5 | 各テーブルのデータ（Admin APIで読み書き） |
