# ユーザーストーリー: FR-7 管理画面（Web）

## 概要

- **対象機能**: FR-7 管理画面
- **分解アプローチ**: Feature-Based
- **粒度**: 細かめ（数時間〜1日）
- **受け入れ基準フォーマット**: Given-When-Then（BDD）
- **ペルソナ**: 管理者（開発者）
- **プラットフォーム**: React Web アプリ
- **備考**: 旧 stories-admin.md（US-1.7〜US-1.9）の内容を本ファイルに統合

## 管理者認証

### US-7.1: 管理画面へのログイン

**As a** 管理者（開発者）
**I want to** メールアドレスとパスワードで管理画面にログインしたい
**So that** 管理機能に安全にアクセスできる

**受け入れ基準:**

- Given: 管理画面のログインページにアクセスした場合
  When: 正しいメールアドレスとパスワードを入力してログインボタンを押す
  Then: 管理画面のトップページに遷移する

- Given: 管理画面のログインページにアクセスした場合
  When: 誤ったメールアドレスまたはパスワードを入力してログインボタンを押す
  Then: エラーメッセージが表示され、ログインできない

- Given: ログインしていない状態で管理画面のURLに直接アクセスした場合
  When: ページを読み込む
  Then: ログインページにリダイレクトされる

---

### US-7.2: 管理画面からのログアウト

**As a** 管理者（開発者）
**I want to** 管理画面からログアウトしたい
**So that** 作業終了後にセッションを安全に終了できる

**受け入れ基準:**

- Given: 管理画面にログインしている場合
  When: ログアウトボタンを押す
  Then: セッションが破棄され、ログインページに遷移する

---

## ユーザー管理

### US-7.3: ユーザー一覧の閲覧・検索

**As a** 管理者（開発者）
**I want to** ユーザーの一覧を閲覧・検索したい
**So that** 特定のユーザーを素早く見つけて状態を確認できる

**受け入れ基準:**

- Given: 管理画面にログインしている場合
  When: ユーザー管理ページを開く
  Then: ユーザー一覧がページネーション付きで表示される（ID、ニックネーム、メールアドレス、ステータス、登録日、最終ログイン日）

- Given: ユーザー一覧画面にいる場合
  When: メールアドレスまたはニックネームで検索する
  Then: 該当するユーザーがフィルタリングされて表示される

- Given: ユーザー一覧画面にいる場合
  When: ステータス（有効/停止/削除済み）でフィルタリングする
  Then: 該当ステータスのユーザーのみ表示される

---

### US-7.4: ユーザー詳細の閲覧

**As a** 管理者（開発者）
**I want to** ユーザーの詳細情報を閲覧したい
**So that** ユーザーの状態を正確に把握できる

**受け入れ基準:**

- Given: ユーザー一覧画面にいる場合
  When: ユーザーの行をクリックする
  Then: ユーザー詳細画面に遷移し、プロフィール情報（ニックネーム、メールアドレス、登録日、最終ログイン日、ステータス）が表示される

- Given: ユーザー詳細画面にいる場合
  When: ゲームデータタブを選択する
  Then: ぶたのレベル、ポイント、進化段階、スキル構成、バトル戦績が表示される

---

### US-7.5: ユーザープロフィールの編集

**As a** 管理者（開発者）
**I want to** ユーザーのプロフィール情報を編集したい
**So that** テスト・デバッグ時にユーザーデータを調整できる

**受け入れ基準:**

- Given: ユーザー詳細画面にいる場合
  When: 「編集」ボタンを押してニックネームやメールアドレスを変更し、保存する
  Then: 変更が反映され、成功メッセージが表示される

- Given: プロフィール編集中の場合
  When: 必須項目を空にして保存しようとする
  Then: バリデーションエラーが表示され、保存されない

---

### US-7.6: ユーザーアカウントの停止・復活

**As a** 管理者（開発者）
**I want to** ユーザーのアカウントを停止・復活させたい
**So that** 不正利用や規約違反に対応できる

**受け入れ基準:**

- Given: 有効なユーザーの詳細画面を開いている場合
  When: 「アカウント停止」ボタンを押す
  Then: 確認ダイアログが表示され、確認後にアカウントが停止され、該当ユーザーはログインできなくなる

- Given: 停止中のユーザーの詳細画面を開いている場合
  When: 「アカウント復活」ボタンを押す
  Then: アカウントが復活し、該当ユーザーが再びログインできるようになる

---

### US-7.7: ユーザーの論理削除

**As a** 管理者（開発者）
**I want to** ユーザーを論理削除したい
**So that** データを保持しつつユーザーを無効化できる

**受け入れ基準:**

- Given: ユーザー詳細画面を開いている場合
  When: 「削除」ボタンを押す
  Then: 確認ダイアログが表示され、確認後にユーザーに削除フラグが設定される

- Given: ユーザーが論理削除された場合
  When: 該当ユーザーがアプリにログインしようとする
  Then: ログインが拒否される

- Given: ユーザー一覧画面でステータスフィルタを「削除済み」にした場合
  When: 一覧を表示する
  Then: 論理削除されたユーザーが表示される

---

## ゲームデータ管理

### US-7.8: 個別ユーザーのゲームデータ修正

**As a** 管理者（開発者）
**I want to** 個別ユーザーのゲームデータを修正したい
**So that** テスト・デバッグ時に任意の状態を再現できる

**受け入れ基準:**

- Given: ユーザー詳細画面のゲームデータタブにいる場合
  When: 「ゲームデータ編集」ボタンを押す
  Then: ぶたのレベル、ポイント、進化段階を編集できるフォームが表示される

- Given: ゲームデータ編集フォームにいる場合
  When: 値を変更して保存する
  Then: 変更が即座に反映され、成功メッセージが表示される

- Given: ゲームデータ編集フォームにいる場合
  When: 不正な値（負のポイント、存在しない進化段階等）を入力して保存する
  Then: バリデーションエラーが表示され、保存されない

---

### US-7.9: ユーザーのバトル履歴閲覧・修正

**As a** 管理者（開発者）
**I want to** ユーザーのバトル履歴を閲覧・修正したい
**So that** バトル関連のデバッグやデータ確認ができる

**受け入れ基準:**

- Given: ユーザー詳細画面のゲームデータタブにいる場合
  When: バトル履歴セクションを表示する
  Then: 対戦日時、対戦相手、勝敗、ポイント変動の一覧が表示される

- Given: バトル履歴の詳細を開いている場合
  When: ポイント変動の値を編集して保存する
  Then: 変更が反映され、成功メッセージが表示される

---

## マスターデータ管理

### US-7.10: 進化パスの管理

**As a** 管理者（開発者）
**I want to** ぶたの進化パスを閲覧・編集・追加・削除したい
**So that** ゲームバランスの調整や新しい進化パスの追加ができる

**受け入れ基準:**

- Given: マスターデータ管理ページを開いた場合
  When: 「進化パス」タブを選択する
  Then: 進化パスの一覧（名前、条件、ステータス変化）が表示される

- Given: 進化パス一覧にいる場合
  When: 「新規追加」ボタンを押して進化パス情報を入力し保存する
  Then: 新しい進化パスが追加され、一覧に表示される

- Given: 進化パスの詳細を開いている場合
  When: 条件やステータス変化を編集して保存する
  Then: 変更が反映される

- Given: 進化パスの詳細を開いている場合
  When: 「削除」ボタンを押す
  Then: 確認ダイアログが表示され、確認後に進化パスが削除される

---

### US-7.11: スキル定義の管理

**As a** 管理者（開発者）
**I want to** バトルスキルの定義を閲覧・編集・追加・削除したい
**So that** スキルバランスの調整や新スキルの追加ができる

**受け入れ基準:**

- Given: マスターデータ管理ページを開いた場合
  When: 「スキル定義」タブを選択する
  Then: スキル一覧（名前、タイプ、威力、効果、クールタイム）が表示される

- Given: スキル一覧にいる場合
  When: 「新規追加」ボタンを押してスキル情報を入力し保存する
  Then: 新しいスキルが追加され、一覧に表示される

- Given: スキルの詳細を開いている場合
  When: 威力や効果を編集して保存する
  Then: 変更が反映される

- Given: スキルの詳細を開いている場合
  When: 「削除」ボタンを押す
  Then: 確認ダイアログが表示され、確認後にスキルが削除される
