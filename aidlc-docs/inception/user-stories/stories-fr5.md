# ユーザーストーリー: FR-5 リアルタイムバトルシステム

## 概要

- **対象機能**: FR-5 リアルタイムバトルシステム
- **分解アプローチ**: Feature-Based
- **粒度**: 細かめ（数時間〜1日）
- **受け入れ基準フォーマット**: Given-When-Then（BDD）
- **ペルソナ**: 一般プレイヤー（タケシ）

### バトル仕様サマリー

- **形式**: ターン制（両プレイヤー同時選択 → 素早さ順で行動）
- **ターン制限時間**: 20秒
- **バトル制限時間**: 5分
- **操作**: スキル選択（最大4つ）/ 防御 / アイテム使用
- **マッチメイキング**: ランダム（ランダムマッチ + フレンド対戦）
- **マッチング待ち上限**: 30秒
- **勝利報酬**: ランキングポイント獲得
- **敗北ペナルティ**: ランキングポイント減少
- **時間切れ**: 残りHP割合が高い方の勝利
- **切断時**: 自動敗北

---

### US-5.1: ランダムマッチの申し込み

**As a** 一般プレイヤー
**I want to** ランダムな対戦相手とマッチングしたい
**So that** フレンドがいなくてもバトルを楽しめる

**受け入れ基準:**

- Given: ホーム画面またはバトル画面にいる場合
  When: 「ランダムマッチ」ボタンを押す
  Then: マッチング待機画面に遷移し、対戦相手の検索が開始される

- Given: マッチング待機中の場合
  When: 30秒以内に対戦相手が見つかる
  Then: 対戦相手の情報（ニックネーム、ぶたアバター）が表示され、バトル準備画面に遷移する

- Given: マッチング待機中の場合
  When: 30秒経過しても対戦相手が見つからない
  Then: 「対戦相手が見つかりませんでした」と表示され、リトライまたはキャンセルを選択できる

- Given: マッチング待機中の場合
  When: 「キャンセル」ボタンを押す
  Then: マッチングが中止され、元の画面に戻る

---

### US-5.2: フレンド対戦の申し込み

**As a** 一般プレイヤー
**I want to** フレンドを指定してバトルを申し込みたい
**So that** 友達と直接対戦できる

**受け入れ基準:**

- Given: フレンド一覧画面にいる場合
  When: オンライン中のフレンドを選択して「バトルを申し込む」を押す
  Then: フレンドにバトル招待が送信され、応答待ち画面に遷移する

- Given: バトル招待を送信した場合
  When: フレンドが招待を承諾する
  Then: バトル準備画面に遷移する

- Given: バトル招待を送信した場合
  When: フレンドが招待を拒否する
  Then: 「対戦が成立しませんでした」と表示され、元の画面に戻る

- Given: バトル招待を送信した場合
  When: フレンドがまだ応答していない
  Then: 応答待ち画面が継続表示され、タイムアウトは発生しない（手動キャンセルのみ）

- Given: アプリ使用中の場合
  When: フレンドからバトル招待を受信する
  Then: バトル招待通知がポップアップ表示され、承諾/拒否を選択できる

---

### US-5.3: バトル準備（スキル・アイテムセット）

**As a** 一般プレイヤー
**I want to** バトル前にスキルとアイテムをセットしたい
**So that** 戦略を立ててバトルに臨める

**受け入れ基準:**

- Given: バトル準備画面に遷移した場合
  When: スキルセット画面が表示される
  Then: ぶたが習得済みのスキル一覧から最大4つを選択できる

- Given: スキルセット画面にいる場合
  When: 各スキルをタップする
  Then: スキルの詳細（ダメージ、効果、クールタイム）が確認できる

- Given: バトル準備画面にいる場合
  When: 使用するアイテムを選択する
  Then: 所持アイテムから持ち込みアイテムをセットできる

- Given: 両プレイヤーが準備完了した場合
  When: 「準備完了」ボタンを押す
  Then: バトルが開始される

- Given: 準備時間（30秒）が経過した場合
  When: まだ準備完了していない
  Then: 現在のセット状態（未選択ならデフォルト構成）でバトルが自動開始される

---

### US-5.4: バトル中のターン操作

**As a** 一般プレイヤー
**I want to** 毎ターン行動を選択してバトルしたい
**So that** 戦略的にバトルを楽しめる

**受け入れ基準:**

- Given: バトル中で自分のターン行動選択フェーズの場合
  When: 行動選択画面が表示される
  Then: 「スキル（最大4つ）」「防御」「アイテム」から1つを選択できる

- Given: 行動選択フェーズの場合
  When: セットしたスキルの1つを選択する
  Then: そのスキルが行動として確定され、相手の選択完了を待つ

- Given: 行動選択フェーズの場合
  When: 「防御」を選択する
  Then: そのターンの被ダメージが半減する行動として確定される

- Given: 行動選択フェーズの場合
  When: 「アイテム」を選択して使用するアイテムを選ぶ
  Then: アイテム使用が行動として確定される

- Given: 行動選択フェーズの場合
  When: 20秒以内に行動を選択しない
  Then: 自動的に「防御」が選択される

- Given: 両プレイヤーの行動が確定した場合
  When: ターンが実行される
  Then: 素早さステータスが高い方から順に行動が実行され、結果がアニメーション付きで表示される

---

### US-5.5: スキルのクールタイム管理

**As a** 一般プレイヤー
**I want to** スキルのクールタイムを把握したい
**So that** 使用可能なスキルを判断して戦略を立てられる

**受け入れ基準:**

- Given: バトル中の行動選択フェーズの場合
  When: スキル一覧が表示される
  Then: クールタイム中のスキルはグレーアウトされ、残りターン数が表示される

- Given: クールタイム中のスキルがある場合
  When: そのスキルをタップする
  Then: 「あとXターンで使用可能」と表示され、選択はできない

- Given: クールタイムが終了したスキルがある場合
  When: 次のターンの行動選択フェーズになる
  Then: そのスキルが再び選択可能になる

---

### US-5.6: バトル中のリアルタイム状態表示

**As a** 一般プレイヤー
**I want to** バトル中に両者の状態をリアルタイムで確認したい
**So that** 戦況を把握して判断できる

**受け入れ基準:**

- Given: バトル中の場合
  When: バトル画面が表示されている
  Then: 自分と相手のHP（バー + 数値）、ぶたアバター、ニックネームが常時表示される

- Given: バトル中の場合
  When: バフ/デバフ効果が発動中である
  Then: 該当プレイヤーのアバター付近にステータス変化アイコンと残りターン数が表示される

- Given: バトル中の場合
  When: 画面上部を確認する
  Then: バトル残り時間（5分からのカウントダウン）と現在のターン数が表示される

---

### US-5.7: バトル終了と結果表示

**As a** 一般プレイヤー
**I want to** バトル結果を確認したい
**So that** 勝敗とランキングポイントの変動を把握できる

**受け入れ基準:**

- Given: どちらかのHPが0になった場合
  When: バトルが終了する
  Then: 勝敗結果画面が表示され、勝者には「WIN」、敗者には「LOSE」と表示される

- Given: バトル制限時間（5分）が経過した場合
  When: 両者のHPが残っている
  Then: 残りHP割合が高い方が勝者となり、結果画面が表示される

- Given: バトル制限時間経過時に両者のHP割合が同じ場合
  When: バトルが終了する
  Then: 「DRAW（引き分け）」と表示され、ランキングポイントの変動はない

- Given: バトル結果画面が表示された場合
  When: 結果を確認する
  Then: ランキングポイントの増減（例: +15pt / -10pt）が表示される

- Given: バトル結果画面が表示された場合
  When: 「戻る」ボタンを押す
  Then: ホーム画面に遷移する

---

### US-5.8: バトル中の接続切断対応

**As a** 一般プレイヤー
**I want to** 相手が切断した場合にバトルが適切に終了してほしい
**So that** 切断による不利益を受けない

**受け入れ基準:**

- Given: バトル中に自分の接続が切断された場合
  When: 再接続できない
  Then: 自動敗北となり、ランキングポイントが減少する

- Given: バトル中に相手の接続が切断された場合
  When: 相手が再接続しない
  Then: 自分の勝利扱いとなるが、ランキングポイントの変動はない（切断勝利ではポイント増加しない）

- Given: バトル中にどちらかの接続が切断された場合
  When: 切断が検出される
  Then: 接続中のプレイヤーに「相手の接続が切断されました」と表示され、数秒後に勝利判定となる

---

### US-5.9: バトル履歴の閲覧

**As a** 一般プレイヤー
**I want to** 過去のバトル履歴を確認したい
**So that** 自分の戦績を振り返れる

**受け入れ基準:**

- Given: バトル画面またはプロフィール画面にいる場合
  When: 「バトル履歴」を開く
  Then: 過去のバトル一覧が新しい順に表示される（対戦相手、勝敗、日時）

- Given: バトル履歴一覧にいる場合
  When: 特定のバトルをタップする
  Then: バトル詳細（使用スキル、ターン経過、ポイント増減）が表示される

---

### US-5.10: ランキング表示

**As a** 一般プレイヤー
**I want to** ランキングを確認したい
**So that** 自分の順位や他プレイヤーとの差を把握できる

**受け入れ基準:**

- Given: ランキング画面を開いた場合
  When: ランキング一覧が表示される
  Then: ランキングポイント順に上位プレイヤー（ニックネーム、ぶたアバター、ポイント）が表示される

- Given: ランキング画面にいる場合
  When: 自分の順位を確認する
  Then: 自分の現在の順位とポイントがハイライト表示される

### INVEST基準の根拠

- **Independent（独立）**: マッチング、バトル操作、結果表示、履歴・ランキングがそれぞれ独立して実装・テスト可能
- **Negotiable（交渉可能）**: ターン制限時間、クールタイム値、ランキングポイント増減量は調整可能
- **Valuable（価値がある）**: 各ストーリーがリアルタイム対戦というコア体験に直結
- **Estimable（見積可能）**: 各ストーリーは数時間〜1日で実装可能な粒度
- **Small（小さい）**: マッチング/バトル操作/結果/履歴と機能単位で分離
- **Testable（テスト可能）**: BDD形式の受け入れ基準により明確にテスト可能
