# ユーザーストーリー: FR-1 ユーザー認証（管理者向け）

## 概要

- **対象機能**: FR-1 ユーザー認証（管理画面）
- **分解アプローチ**: Feature-Based
- **粒度**: 細かめ（数時間〜1日）
- **受け入れ基準フォーマット**: Given-When-Then（BDD）
- **ペルソナ**: 管理者（開発者）

---

### US-1.7: ユーザー一覧の閲覧・検索

**As a** 管理者（開発者）
**I want to** ユーザーの一覧を閲覧・検索したい
**So that** 特定のユーザーを素早く見つけて状態を確認できる

**受け入れ基準:**

- Given: 管理画面にログインしている場合
  When: ユーザー管理ページを開く
  Then: ユーザー一覧がページネーション付きで表示される

- Given: ユーザー一覧画面にいる場合
  When: メールアドレスまたはニックネームで検索する
  Then: 該当するユーザーがフィルタリングされて表示される

---

### US-1.8: ユーザーアカウントの停止・復活

**As a** 管理者（開発者）
**I want to** 問題のあるユーザーのアカウントを停止・復活させたい
**So that** 不正利用や規約違反に対応できる

**受け入れ基準:**

- Given: ユーザー詳細画面を開いている場合
  When: 「アカウント停止」ボタンを押す
  Then: 確認ダイアログ後にアカウントが停止され、該当ユーザーはログインできなくなる

- Given: 停止中のユーザーの詳細画面を開いている場合
  When: 「アカウント復活」ボタンを押す
  Then: アカウントが復活し、該当ユーザーが再びログインできるようになる

---

### US-1.9: パスワードリセット

**As a** 管理者（開発者）
**I want to** ユーザーのパスワードをリセットしたい
**So that** パスワードを忘れたユーザーのサポートができる

**受け入れ基準:**

- Given: ユーザー詳細画面を開いている場合
  When: 「パスワードリセット」ボタンを押す
  Then: 該当ユーザーにパスワードリセットメールが送信される
