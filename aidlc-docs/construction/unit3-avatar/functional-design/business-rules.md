# Business Rules - Unit 3: アバター育成

## BR-1: レベル計算（緩やかな指数曲線）

**計算式**: レベルNに到達するために必要な累計ポイント = `N × (N + 1) × 50`

| レベル | 必要累計ポイント | 前レベルからの差分 |
|--------|-----------------|-------------------|
| 1 | 100 | 100 |
| 2 | 300 | 200 |
| 3 | 600 | 300 |
| 4 | 1,000 | 400 |
| 5 | 1,500 | 500 |
| 10 | 5,500 | 1,000 |
| 15 | 12,000 | 1,500 |
| 20 | 21,000 | 2,000 |

**ルール**:
| ルール | 条件 |
|--------|------|
| レベル上限 | 30（ハッカソン規模） |
| レベルアップ判定 | totalPoints >= 次レベル必要ポイント時に即時 |
| レベルダウン判定 | totalPoints < 現レベル必要ポイント時に即時 |
| 最低レベル | 1（totalPointsが0以下でもレベル1を維持） |

## BR-2: 進化条件

### 進化段階とレベル要件

| 進化段階 | 必要レベル | 追加条件 |
|---------|-----------|---------|
| 第1段階（初期） | Lv 1 | なし（初期状態） |
| 第2段階 | Lv 5 | カテゴリ比率判定 |
| 第3段階（最終） | Lv 15 | カテゴリ比率判定 + 第2段階の進化パス |

### カテゴリ比率による進化パス自動判定

| 条件 | 進化パス |
|------|---------|
| FOOD比率 ≥ 60% | 食事系パス |
| LIFESTYLE比率 ≥ 60% | 生活系パス |
| どちらも60%未満 | 混合パス |

**比率計算**: `categoryPoints[FOOD] / totalPoints` および `categoryPoints[LIFESTYLE] / totalPoints`

### 進化パス一覧（第2段階）

| pathId | 名前 | dominantCategory | 説明 |
|--------|------|-----------------|------|
| food_stage2 | グルメぶた | FOOD | 食事系不健康行動が多い |
| lifestyle_stage2 | ぐうたらぶた | LIFESTYLE | 生活系不健康行動が多い |
| mixed_stage2 | まんまるぶた | MIXED | バランスよく不健康 |

### 進化パス一覧（第3段階）

第2段階以降に記録した行動のサブカテゴリ傾向で分岐。

| pathId | 名前 | parentPathId | 分岐条件 | 説明 |
|--------|------|-------------|---------|------|
| food_gorge_stage3 | 暴食帝ぶた | food_stage2 | 暴飲暴食・ジャンクフード比率 ≥ 50% | 量で攻める大食い型 |
| food_gourmet_stage3 | 夜食神ぶた | food_stage2 | 深夜ラーメン・間食比率 ≥ 50% | 時間帯で攻める夜食型 |
| life_night_stage3 | 不夜城ぶた | lifestyle_stage2 | 夜更かし・二度寝比率 ≥ 50% | 睡眠を犠牲にする夜型 |
| life_sloth_stage3 | 万年床ぶた | lifestyle_stage2 | 運動サボり・だらだら動画比率 ≥ 50% | 動かない怠惰型 |
| mixed_chaos_stage3 | 大魔王ぶた | mixed_stage2 | 食事系比率が高め（40-59%） | カオスな食寄り万能型 |
| mixed_entropy_stage3 | 混沌王ぶた | mixed_stage2 | 生活系比率が高め（40-59%） | カオスな生活寄り万能型 |

**第3段階の分岐判定ロジック**:
- 第2段階進化後に記録したカテゴリ内のサブカテゴリ（categoryId）比率で判定
- グルメぶた: food_binge + food_junkfood vs food_late_ramen + food_snack
- ぐうたらぶた: life_stay_up + life_oversleep vs life_skip_exercise + life_binge_watch
- まんまるぶた: 全体のFOOD比率 vs LIFESTYLE比率（60%未満の範囲内で比較）
- どちらも50%未満（完全均等）の場合: ランダムで決定

## BR-3: 退化条件

| ルール | 条件 |
|--------|------|
| 退化トリガー | totalPointsが現在の進化段階の必要レベルを下回った時 |
| 退化先 | 1つ前の進化段階に戻る |
| スキル喪失 | 現在の進化段階で習得したスキルを失う |
| 退化後の進化パス | 前段階のパスに戻る（第3→第2: parentPathIdの進化パスへ） |
| 第2段階→第1段階 | evolutionPathId = null に戻る |
| 連続退化 | 可能（第3→第2→第1と一気に戻る場合あり） |
| 退化演出 | 退化アニメーション再生 |
| 削除起因の退化 | 演出スキップ、通知のみ（Unit 2 BR-8準拠） |

| 習得条件 | 対象スキルの evolutionPathId が現在のパスと一致 & requiredLevel ≤ 現レベル |
| 1パスあたりのスキル数 | 2個 |

## BR-6: 初期アバター生成

| ルール | 条件 |
|--------|------|
| 生成タイミング | 初回ログイン後のプロフィール設定完了時 |
| 初期状態 | レベル1、第1段階、totalPoints=0、初期ステータス |
| アバター名 | ユーザーが設定（デフォルト: 「ぶたさん」） |
| スプライトシート | 初期段階用のデフォルトアセット |
| 1ユーザー1体 | 複数アバター不可 |

## BR-7: スプライトシートアセット管理

| ルール | 条件 |
|--------|------|
| 保存先 | S3バケット（事前アップロード） |
| アセット形式 | PNG スプライトシート |
| アニメーション種類 | idle（待機）、happy（喜び）、sad（退化時）、evolve（進化時） |
| 進化パスごとのアセット | 各パスに1セットのスプライトシート |
| フォールバック | アセット読み込み失敗時は初期段階のスプライトを表示 |

## BR-8: ポイント加算・減算の処理順序

| ルール | 条件 |
|--------|------|
| 加算時の処理順 | ①totalPoints更新 → ②レベル再計算 → ③進化判定 → ④スキル習得判定 → ⑤ステータス再計算 |
| 減算時の処理順 | ①totalPoints更新 → ②レベル再計算 → ③退化判定 → ④スキル喪失判定 → ⑤ステータス再計算 |
| categoryPoints更新 | 加算時: 該当カテゴリに加算。減算時: 該当カテゴリから減算（最低0） |
| 複数レベル変動 | 一度のポイント変動で複数レベル上下する場合、最終レベルで判定 |
