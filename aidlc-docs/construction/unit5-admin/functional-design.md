# Unit 5: 管理画面 (FR-7) — Functional Design

## 設計方針

| 項目 | 設計 |
|---|---|
| 認証 | Basic認証（環境変数でID/PW管理） |
| UIフレームワーク | React + Vite + MUI (Material UI) |
| コーディング方針 | Modern Web Guidance準拠（最新CSS/HTML優先） |
| バックエンド | Hono + OpenAPI（Lambda） |
| 操作ログ | DynamoDBに操作履歴テーブルを追加 |

---

## 画面構成

### 1. ログイン画面
- Basic認証のID/PW入力
- 認証失敗時のエラー表示

### 2. ユーザー管理
- ユーザー一覧（ページネーション付き）
- 検索（ユーザー名、メールアドレス）
- ユーザー詳細（Cognito情報 + アバターデータ）
- アカウント停止 / 復活
- ユーザー削除

### 3. マスターデータ管理
- 進化パス一覧 / 新規登録 / 編集 / 削除
- スキル一覧 / 新規登録 / 編集 / 削除
- ゲーム設定（初期ステータス、成長率、レベル上限、進化閾値等の定数変更）

### 4. ゲームデータ修正
- 個別ユーザーのアバターデータ修正（レベル、ポイント、進化段階等）
- ヘルスデータ手動入力（体重・BMI、歩数、睡眠データを管理者が代理入力）

### 5. 操作ログ閲覧
- 誰がいつ何をしたかの履歴表示
- フィルタリング（操作種別、日時）
