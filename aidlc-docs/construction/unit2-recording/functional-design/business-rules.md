# Business Rules - Unit 2: 行動記録 + ヘルスデータ連携

## BR-1: 手動記録ポイント計算

| カテゴリタイプ | 基本ポイント | 備考 |
|-------------|------------|------|
| FOOD（食事系） | 12pt | 深夜ラーメン、暴飲暴食、間食等 |
| LIFESTYLE（生活系） | 10pt | 夜更かし、二度寝、運動サボり等 |

| ルール | 条件 |
|--------|------|
| 1日の記録回数上限 | なし（何回でも記録可能） |
| 同一カテゴリの連続記録 | 制限なし |
| ポイント付与タイミング | 記録完了時に即時加算 |

## BR-2: ヘルスデータ自動検出ポイント計算

### 体重変動

| 条件 | ポイント | 評価 |
|------|---------|------|
| +1kg以上 | +20pt × 増加kg数 | UNHEALTHY |
| -1kg以上 | -10pt × 減少kg数 | HEALTHY |
| ±1kg未満 | 0pt | NEUTRAL |

**比較基準**: 前回同期時の体重値

### 歩数

| 条件 | ポイント | 評価 |
|------|---------|------|
| 0歩 | +12pt | UNHEALTHY |
| 1〜7999歩 | +5〜+12pt（線形補間） | UNHEALTHY |
| 8000歩以上 | -3〜-8pt（線形補間、上限15000歩） | HEALTHY |

**歩数不足の計算式**: `points = 12 - (steps / 8000) × 7`（小数切り捨て）
**歩数超過の計算式**: `points = -(3 + (steps - 8000) / 7000 × 5)`（小数切り捨て、最大-8）

### 夜更かし（就寝時刻）

| 条件 | ポイント | 評価 |
|------|---------|------|
| 就寝 > 基準値（23:00） | +8pt + 3pt × 超過時間 | UNHEALTHY |
| 就寝 ≤ 基準値 | -4pt | HEALTHY |

**超過時間**: 30分単位で切り捨て（例: 0:15→0h, 0:45→0.5h）

### 睡眠不足

| 条件 | ポイント | 評価 |
|------|---------|------|
| 睡眠時間 < 基準値（7h） | +6pt + 2pt × 不足時間 | UNHEALTHY |
| 基準値 ≤ 睡眠時間 < 基準値+2h | -3pt | HEALTHY |
| 睡眠時間 ≥ 基準値+2h（9h） | +4pt + 1pt × 超過時間 | UNHEALTHY |

### 起床時刻

| 条件 | ポイント | 評価 |
|------|---------|------|
| 起床 > 基準値（7:00） | +6pt + 2pt × 超過時間 | UNHEALTHY |
| 起床 ≤ 基準値 | -3pt | HEALTHY |

## BR-3: 同期タイミングルール

| ルール | 条件 |
|--------|------|
| 同期頻度 | 1日1回、その日の初回アプリ起動時 |
| 同期対象期間 | 前回同期日の翌日〜前日（当日は含まない） |
| 2回目以降の起動 | 同期スキップ（同日判定はlastSyncDatesで管理） |
| オフライン時 | 同期スキップ、次回オンライン起動時にまとめて同期 |
| 複数日未起動 | 未同期日分をすべて個別に評価しポイント合算 |

## BR-4: カテゴリ別同期設定

| ルール | 条件 |
|--------|------|
| デフォルト状態 | 全カテゴリON |
| カテゴリOFF時 | 該当カテゴリのデータ取得・評価を停止 |
| カテゴリON復帰時 | 復帰タイミング以降のデータのみ同期（過去分は取り込まない） |
| 連携解除時 | 全カテゴリの同期停止、既存データは保持 |
| 連携再有効化 | OS許可ダイアログ再表示→許可後に同期再開 |

## BR-5: メモフィールド制約

| ルール | 条件 |
|--------|------|
| 最大文字数 | 100文字 |
| 必須/任意 | 任意 |
| 使用可能文字 | 制限なし（絵文字含む） |

## BR-6: 記録操作制約

| ルール | 条件 |
|--------|------|
| 記録タップ数 | 3タップ以内（カテゴリ選択→確認→記録） |
| 日時変更 | 任意（デフォルト: 現在時刻） |
| 自動検出レコードの削除 | 可能（ポイント取り消し） |
| 手動記録の削除 | 不可（一度記録したら取り消せない） |

## BR-7: オフライン行動記録

| ルール | 条件 |
|--------|------|
| オフライン記録 | ローカルDBに保存 |
| 同期タイミング | ネットワーク復帰時に自動送信 |
| 競合解決 | サーバー側にレコードがなければ追加（recordIdで一意） |
| ポイント反映 | サーバー同期完了後にアバターサービスへ通知 |

## BR-8: アバター連携（同期方式）

| ルール | 条件 |
|--------|------|
| 通知タイミング | 記録完了APIレスポンス内でアバターステータス更新 |
| レスポンス内容 | 更新後のアバターステータス（レベル、ポイント、ステータス値） |
| ヘルスデータ同期時 | 一括同期APIレスポンス内でまとめてアバター更新結果を返却 |
| オフライン記録同期時 | 同期完了レスポンスにアバター更新結果を含む |

## BR-9: サマリー表示ルール

| ルール | 条件 |
|--------|------|
| 起動時サマリー表示条件 | 自動検出で1件以上の行動が検出された場合のみ |
| サマリー非表示条件 | 検出0件 or 同日2回目以降の起動 |
| ホーム画面サマリー | 今日の記録件数 + 合計ポイント（常時表示） |
| 週間サマリー | カテゴリ別記録件数 + ポイント内訳（タップで展開） |

## BR-10: 記録履歴ページネーション

| ルール | 条件 |
|--------|------|
| 表示方式 | 「もっと見る」ボタン |
| 1ページあたり件数 | 20件 |
| ソート順 | recordedAt降順（新しい順） |
| フィルター | 日付範囲、カテゴリ |
