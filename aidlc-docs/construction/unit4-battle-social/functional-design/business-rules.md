# Unit 4: バトル + ソーシャル - ビジネスルール

## BR-1: ダメージ計算

```text
baseDamage = max(1, attacker.attack - defender.defense)
randomFactor = 0.9 + (random() * 0.2)   // ±10%
categoryBonus = getCategoryBonus(skill, defender)  // 1.0 or 1.3
finalDamage = floor(baseDamage * skill.power / 100 * randomFactor * categoryBonus)
```

- 最低ダメージ: 1
- 防御選択時: `finalDamage = floor(finalDamage * 0.5)`

---

## BR-2: カテゴリ相性

| 攻撃側カテゴリ | 防御側アバター主カテゴリ | 倍率 |
|--------------|---------------------|------|
| FOOD | LIFESTYLE育ちのアバター | 1.3x（有利） |
| LIFESTYLE | FOOD育ちのアバター | 1.3x（有利） |
| 同カテゴリ | - | 1.0x（等倍） |

- アバターの「主カテゴリ」= 累計ポイントが多い方のカテゴリ
- 相性ボーナス発動時、UIに「効果抜群！」表示

---

## BR-3: バフ/デバフ適用

- バフ: ステータスに `value%` 加算（例: ATK_UP 20% → attack * 1.2）
- デバフ: ステータスに `value%` 減算（例: DEF_DOWN 15% → defense * 0.85）
- 同種バフ重複: 上書き（後から適用した方が有効）
- 毎ターン終了時に `remainingTurns--`、0になったら解除

---

## BR-4: ターン実行順序

1. 両プレイヤーが行動選択（20秒制限、未選択は自動「防御」）
2. 素早さ比較: `speed` が高い方が先攻
3. 同速の場合: ランダムで先攻決定
4. 先攻の行動実行 → ダメージ/効果適用
5. 後攻のHP > 0 なら後攻の行動実行
6. ターン終了処理（バフ残ターン減少、クールダウン減少）

---

## BR-5: スキルクールダウン

- スキル使用後: `currentCooldown = skill.cooldown`
- 毎ターン終了時: `currentCooldown = max(0, currentCooldown - 1)`
- `currentCooldown > 0` のスキルは選択不可

---

## BR-6: 勝敗判定

| 条件 | 結果 |
|------|------|
| 相手HP ≤ 0 | KO勝利 |
| 5分経過 & HP割合が高い方 | TIMEOUT勝利 |
| 5分経過 & HP割合同じ | DRAW |
| 相手切断（再接続なし） | DISCONNECT勝利 |
| 自分切断 | 自動敗北 |

---

## BR-7: ランキングポイント計算（Eloレーティング風）

```text
K = 32
expectedScore = 1 / (1 + 10^((opponentPoints - myPoints) / 400))

勝利時: pointChange = round(K * (1 - expectedScore))
敗北時: pointChange = round(K * (0 - expectedScore))  // 負の値
引き分け: pointChange = round(K * (0.5 - expectedScore))
```

- 初期ポイント: 1000
- 最低ポイント: 0（0未満にはならない）
- 切断勝利: 勝者のポイント変動なし（切断者のみ減少）

---

## BR-8: マッチメイキング

1. キューに入る（userId, level, rankingPoints, queuedAt）
2. マッチング条件:
   - 第1優先: レベル差 ±5 以内の相手
   - 15秒経過後: レベル差 ±10 に拡大
   - 25秒経過後: 条件なし（誰でもマッチ）
3. 条件を満たす相手が見つかったらマッチ成立
4. 30秒経過で相手なし → タイムアウト通知

---

## BR-9: フレンド対戦招待

1. 招待送信 → 相手にWebSocket通知
2. 相手が承認 → Match作成、PREPARING状態
3. 相手が拒否 → 招待者に通知
4. 手動キャンセルのみ（タイムアウトなし）

---

## BR-10: バトル準備

- 準備時間: 30秒
- スキル選択: 習得済みスキルから最大4つ
- 未選択で時間切れ: デフォルト構成（習得順で先頭4つ）
- 両者「準備完了」or 30秒経過 → バトル開始

---

## BR-11: 接続切断処理

- 切断検出: WebSocket onDisconnect イベント
- 猶予時間: 10秒（再接続待機）
- 10秒以内に再接続: バトル継続（ターンタイマーは停止しない）
- 10秒経過で再接続なし: 敗北判定
- 切断者: 敗北 + ランキングポイント減少
- 接続中プレイヤー: 勝利扱い、ポイント変動なし
- 切断中の相手画面: 「相手の接続が不安定です...」表示

---

## BR-12: フレンド申請ルール

- 自分自身への申請: 不可
- 既にフレンドの相手への申請: 不可
- 既に申請済みの相手への再申請: 不可
- 相手から申請が来ている場合: 自動承認（相互申請）
- 拒否後の再申請: 可能

---

## BR-13: フレンドオンライン判定

```text
isOnline = (now - lastActiveAt) < 5分
```

- lastActiveAt更新タイミング: API呼び出し時、WebSocket メッセージ送信時
- フレンド一覧取得時にリアルタイム計算

---
